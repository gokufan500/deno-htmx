render notes

Page starts with deno.serve, which hosts at port and runs function router;

Deno.serve({port: PORT}, router);

router gets url from req: Request, then matches url to function. by default loads home function. HTMX requests are urls, which are then matched and returned.

difference in htmx ajax requests. get is different from rest, saved in url and cached by browser. rest are similar but have semantic differences

htmx does the same thing for all, issuing a request to server and then expecting return that it then replaces document element with returned html.

  • GET gets user
  • POST create new user
  • PUT replace user entirely
  • PATCH replace user partially
  • DELETE delete user
